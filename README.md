# AppWeatherMovil

1. Nombre del proyecto: AppMovilClima

2. Integrantes: Martin Carrasco y Victor Araujo

3. La app permite buscar una ciudad y al buscarla esta te otorga informacion sobre el clima y las temperaturas actuales de esta misma ademas que las ciudades buscadas se guardan en un historial al cual se puede acceder mediante un boton y ahi se puede observar las ciudades buscadas mostrando la hora a la que fue buscada junto con los datos del clima de ese momento

4. API utilizada: OpenWeatherMap para obtener los datos en tiempo real de las ciudades buscadas y tambien se utilizo sqlite para adminstrar la base de datos

5. Para ejecutar el proyecto es recomendable instalar el plugin "JSON to Kotlin class" y al estar instalado y el proyecto haya finalizado su compilacion solo con darle play al app funcionará, el uso del app es simple al momento de que esta este abierta solo se busca el nombre de la ciudad a la que se le quiere consultar el clima y se clickea en "Buscar Clima" para que se realice la busqueda y se muestre el resultado, tambien esta el boton "Ver Historial" que le lleva a otra pantalla y te muestra todas las ciudades buscadas anteriormente
